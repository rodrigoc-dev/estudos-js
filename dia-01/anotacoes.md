2-let x const: quando usar cada um:
let é uma variável que pode ser alterada e const é algo constante, ou seja, uma variavel fixa que não se altera durante o código
mas de preferencia sempre usar const para evitar alterações sem querer e bugs

5-null x undefined
null é quando alguém preenche "vazio" de propósito, por exemplo um cliente que não tem numero de telefone e alguém preenche null lá pois sabe que o cliente não tem o numero, enquanto o undefined é quando ninguém preencheu nada, por exemplo, número não foi definido ainda
