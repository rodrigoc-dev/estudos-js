1.O que faz o % e um uso prático dele
o % mostra o resto da divisão, é interessante em casos que queremos saber se é um número é par ou ímpar

2.Diferença entre = e ===
o simbolo = atribui valor à variável e o === é de comparação

3.O que acontece com "5" + 3 e por quê
"5" + 3 concatena os dois elementos, ao invés de somar o numero 5 ao 3 ele só junta o caractere 5 e o 3 formando 53 ao invés de 8, pois ele entende o número 5 entre aspas como string

4.Quando você precisa de if e quando basta a comparação direto
se quisermos ações específicas, é interessante usar if e se for apenas de modo a saber se algo é verdadeiro, podemos usar true or false apenas, sem precisar do if else
